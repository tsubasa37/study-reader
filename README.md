# つづき（study-reader）

勉強資料フォルダの HTML 教材を、前回の続きから読むためのローカル Web アプリです。

## できること

- 本棚: 「前回の続き」と、資料ごとの読了章数・最後に開いた日
- プロジェクト: 資料フォルダの直下にフォルダを作ると、そのフォルダがプロジェクトになり、本棚にカードで並ぶ（冊数・読了章数・続き）。フォルダが1つも無ければ今までどおりの一覧のまま
- 閲覧: 読んでいる位置を自動で保存し、開き直すとそこから始まる。章の目次と既読チェック
- しおり: 今の位置にメモ付きで挟む
- ハイライト: 文章を選んで4色で塗り、メモを書く
- 全文検索（⌘K）: 全教材の本文と、しおり・ハイライトのメモ
- プロジェクトへの移動: 資料の行の「…」から、既存のプロジェクト・新しいプロジェクト・プロジェクトの外へ移せる。ファイルと記録を一緒に動かす（同じ名前の PDF なども一緒に動く）
- 記録の引き継ぎ: 名前を変えたり移動したりした資料の記録を、今のファイルへ移す
- 教材の目次を調整: 教材が自前で持つ目次の幅を境界のドラッグで変える／丸ごと隠して本文を広げる（教材のファイルは書き換えず、表示だけ変える）

## 使い方

```bash
cp study-reader.config.example.json study-reader.config.json   # vaultDir に資料フォルダを書く
npm install
npm start
```

ブラウザで http://127.0.0.1:4700 を開きます（ポートは設定ファイルの `port`）。

| コマンド | 内容 |
|---|---|
| `npm start` | 画面をビルドしてから起動 |
| `npm run dev` | 開発用（API と Vite を同時に起動。画面は http://localhost:5173） |
| `npm test` | テスト |
| `npm run typecheck` | 型チェック |

## 記録の置き場所

資料フォルダの `.study/` に JSON で保存します（`progress.json` / `bookmarks.json` / `highlights.json`）。元の HTML は書き換えません。資料フォルダごとバックアップすれば記録も残ります。

JSON が壊れている場合は、そのファイル名を画面に表示して止まります。直すか別名に移してから開き直してください。

## 対応ブラウザ

ハイライトの表示に CSS Custom Highlight API を使うため、Chrome / Edge / Safari 17.2 以降で開いてください。

## 覚え方の仕組み

- 位置は「画面上端から 80px の線が、どの章のどこにあるか」で覚えます。保存と復元で同じ線を使うので、開き直しても同じ位置に戻ります。章が見つからないときは全体の割合でおおよその位置に戻し、その旨を知らせます
- 既読は、同じ章に合計 4 秒以上とどまり、章の終わりが画面に入ったときに付きます。目次リンクで通り過ぎただけでは付きません（手動での付け外しもできます）
- 教材の目次の幅は、開いたときに実際の寸法を測ってから変えます（列で並ぶ教材は列の幅、固定配置の教材は目次の幅と本文の余白）。ダブルクリックか Home キーで教材の元の幅に戻ります
- 画面が狭く、教材が目次を引き出し式にしまう作りに切り替わったときは、幅のつまみは出ません
- 教材の中の外部リンクは別タブで開きます。ブラウザが別タブを止めた場合は、その旨とリンク先を画面に出します

## 気をつけること

- 章は教材の `id` 付き `section` で数えます。「部」の扉ページも `section` になっている教材では、教材自身の章数より多く数えます
- アプリの「…」→「プロジェクトに移動」から移せば、ファイルと記録が一緒に動くので、あとから直す必要はありません
- Finder で直接動かしたときだけ、記録は「記録だけ残っている資料」に残ります。同じファイル名が1つだけ見つかるときは結び付け先を選んだ状態にしておくので、押して確定してください（自動では実行しません）
- プロジェクトの読了章数は、開いたことのある資料の分だけを合計します（章の数は資料を開いて初めて分かるため）
- 入れ子のフォルダ（`インフラ/ネットワーク/…`）の資料は、直下のフォルダ（`インフラ`）のプロジェクトに入ります
- 同じ教材を複数のタブで同時に開くと、あとから保存した方で上書きされます
- ハイライトは選んだ文章と前後の文字で覚え、開くたびに探し直します。教材を書き換えて文章が無くなると「位置を見失ったハイライト」として残ります
- サーバーは 127.0.0.1 だけで待ち受けます（同じ PC からしか開けません）
